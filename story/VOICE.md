# 文风：这个游戏该用什么声音说话

## 为什么要写这份东西

这个项目的文本前后翻过两次车，方向正好相反。

**第一次**是原始的"AI 腔"：

> 微甜的海风混杂着关西老街烘焙面包的香气扑面而来。
> 她随即露出极其真诚温暖的笑容。
> 当书本上的单词真正变成连接人与人之间善意的桥梁时，那种踏实的成就感，是任何考试分数都替代不了的。

形容词堆叠，情绪由旁白直接宣布，最后一句还替读者总结了意义。

**第二次**是修完之后的"技术报告腔"，也就是我自己的毛病：

> 左边是山。右边是海。
> 海一直在。防波堤挡过它两次。仓库挡过一次。挡完了它还在。
> 折到第七页你停了一下。这些地方都在两个月以后。

看起来干净，实际上是把所有温度一起删掉了。短句、无主语、只陈述、不允许自己有情绪——
这和「池子 116 条，全部可达，冷加载零报错」是同一个人在说话。

两次都错，而且错得对称：一次是**说得太多**，一次是**不肯说**。

---

## 目标：村上春树的写法

不是模仿他的题材（猫、井、爵士乐、双胞胎），是模仿他的**句子怎么动**。
下面每一条都是可以照着做的，不是感觉。

### 1. 句子要有时间。不要赶。

村上的叙述是**不着急的**。一件小事可以用两个从句慢慢铺开，
铺完再用一个短句落下来。节奏是「长、长、短」，不是「短、短、短」。

✗ 玻璃是凉的。你把额头贴上去。
✓ 车窗玻璃凉得恰到好处，是那种一整个上午没人碰过的凉法，
  你把额头贴上去，一直贴到眉骨开始发麻才想起来把它挪开。

### 2. 比喻要偏，而且要具体到不必要

村上的比喻从来不是"像宝石一样闪耀"这种。他会拿一个完全不相干的、
非常日常的东西来比，比得越具体越好，越不该拿来比越好。

✓ 那声音听上去像是有人在很远的地方用勺子敲一只空杯子，
  敲了两下就停了，像是自己也觉得没什么意思。
✓ 她道谢的方式非常郑重，郑重得像是你替她搬了一整套家具，
  而不是捡了一本掉在地上的画册。

### 3. 数字是调味料，不是主料 ⚠️

这一条我第一次写错了，写成"数字是质感"，结果自己照着执行的时候
**每两句就塞一个数字**：五十米、三千个词、三十七下、五分之一、五个音节、四十秒。

那不是村上，那是仪表盘。真人说话不会这样。

**硬规矩：一个场景里最多出现一次精确数字，而且必须是那件事本身
就需要被数的时候。** 别的地方一律用模糊说法——"没几步"、"半天"、
"一小把"、"没多少钱"。

✗ 目测五十米，也许更少。
✓ 近得有点不讲道理。

✗ 三个月，每天四十个，最后一个月还加了量。
✓ 你为这一天背了大半年的单词。

✓（保留的那一次）他从二十六岁开始在这儿吃。← 这个数字是这句话的全部意义

### 3b. 允许有感情，只要不是在做总结 ⚠️

上一版我把所有情绪都删了，删完读起来像监控录像的旁白。
村上的叙述者是**有脾气的**：他会嫌麻烦，会觉得好笑，会承认自己感动，
只是从不把感动说成一句结论。

✗ 那种踏实的成就感，是任何考试分数都替代不了的。 ← 结论
✗ （什么都不写）                                  ← 摄像机
✓ 说完这句话你有点想笑，不是因为好笑，是因为它居然就这么成了。

情绪词可以直接用：高兴、烦、想哭、松了口气。
不能用的是**替读者定性的那种句子**。

### 4. 允许跑题，跑完再回来

这是村上最好认的一件事。叙述到一半，主角会想起一件不相干的事，
说完那件事，再回到原来的地方。跑题的那一段**必须自己站得住**，
不能是为了跑题而跑题。

✓ 你把手账翻到中间某一页。……说到手账这个东西，你外公有一个坚持：
  他从来不用圆珠笔，只用钢笔，理由是圆珠笔写出来的字"没有轻重"。
  你小时候听不懂这句话。现在看着这一页深浅不一的墨迹，你大概懂了一点。

### 5. 情绪可以说，但要绕着说

不要"你感到踏实"，也不要什么都不说。村上的做法是**用一个类比或者
一个身体反应把情绪落地**，让读者自己接。

✗ 你心里意外地踏实。
✗ （什么都不写）
✓ 你在房间正中间站了一会儿，感觉像是刚把一件很重的行李放下来，
  但两只手还保持着提着它的形状。

### 6. 自嘲，而且是温和的那种

主角对自己有距离感。他会承认自己刚才那个念头很蠢，
但不会因此贬低自己。「やれやれ」那种劲儿。

✓ 你为了今天背了三千多个日语单词。而此刻你脑子里唯一浮上来的
  是「好近」这两个字。三千多个词，用掉了两个。

### 7. 重复是节奏，不是啰嗦

同一个词或者同一个结构重复两三次，是村上制造节奏的主要办法。
但重复的必须是**有意义的那个词**。

✓ 海一直在那儿。防波堤把它挡掉了一次，又一次；一排仓库把它挡掉了一次。
  每一次它都在你以为它不见了的时候重新出现，
  像是有人在跟你确认什么。

### 8. 人称保持"你"

村上是第一人称，但这个游戏是恋爱模拟，主角是玩家自己。
改成"我"会毁掉这个前提。
**所以：保留"你"，但把村上的句子机制搬过来。**
第二人称加上这套写法是成立的——它读起来像有人在旁边跟你讲你自己的事。

---

## 一句话总结

**说得慢一点，绕一点，允许自己有情绪，但别替读者下结论。**

前一版的问题是替读者下结论。这一版之前的问题是不肯说话。
现在要的是：会说话，而且说得从容。
